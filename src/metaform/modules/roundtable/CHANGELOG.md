# Changelog

Each change to the roundtable module, newest first.

## Unreleased

- The model each harness seat really was, BASE-066: a seat's row keeps `reported`, the model its agent reports its session runs (the current value of the session's model setting), read as the seat's session is found and again after each turn, and `status` gives a harness seat's whole `session` id and `reported`. Two sessions of one agent started at once share their first characters, as Codex's time-ordered ids do, so a short id is no evidence two seats share one. The tables go to version 5, compatible from 1: `seats.reported`.
- The page's reads, BASE-066: `scene <discussion>`, the table as the scene module draws it, and `seats`, the agents with their models and OpenRouter's models a table can be opened with, with the limits and pause in force; both on the command line only, for the web page's Roundtable tab and Open roundtable form. `seats.listed_models` reads OpenRouter's list from the day's cache, as `sees` did. No table changes.
- Limits on rounds and spend, BASE-066 (draft amendment `artifacts/specs-draft/roundtable-limits.md`): the `person_only` settings `roundtable_rounds` (8) and `roundtable_spend` (2 US dollars). A table ends itself the normal way, its report written, after its last round or once it has spent its most through OpenRouter, counted from the usage cost OpenRouter returns for its model seats, Jev and an OpenRouter reporter, and its reason says which, the prompts `ended_rounds` and `ended_spend`. `open` takes `rounds=` and `spend=` for one table; a head agent may set them only at or below the settings. `status` gives `rounds`, `spend` and `spent`. An HTTP 402 from OpenRouter on a model seat's turn raises `seats.Unpaid` and holds the table once with the reason, `held_credits`, in place of passing the turn every round. The tables go to version 4, compatible from 1: `discussions.rounds`, `spend` and `spent`.

- The head agent goes by its name, BASE-066: a comment the head agent makes as chair is credited to the name made from the model its session's harness runs, as a seat's is (Opus, Astra; Claude when no model is listed; with 2 when a seat has it), `names.head` and `chair.head_name`, kept on the comment's `submissions.name`, in place of "the head agent", which stays for comments made before and for a session dispatch cannot place. `status` gives whose turn it is by name, `turn_of`. No table changes.
- The table as a place, BASE-066: every seat has a short name made from its model (Astra, Gemini, Haiku, DeepSeek, GLM; a repeat takes 2, then 3), `names.py`, kept on its row and credited on every turn, in Jev's state, the review, the record and `status`. The seats sit in speaking order round a round table with a plant in the middle, each a fixed figure from the web page's `agents3d.js` that turns in place, `scene.py` and `resources/scene/`. Every seat's controls, `controls.py`: the verbs `rotate`, `look` and `look-at`, declared `read`, acting only for the caller's own seat (a harness seat by its dispatch session, an agent seat by its table, seat and answering session); a look's picture is MCP image content. A model seat's turn is a tool loop with the same controls as tools, `toolloop.py`, its picture given to models that take images. Before the first turn every seat explores its controls for `roundtable_explore` seconds (60), sent "Please take a moment to explore your controls.", `explore.py`. The runner's own loopback watch server and headless Chromium renderer, `stage.py`, its address shown by `status` as `watch`. The tables go to version 3, compatible from 1: `discussions.explored`, `explore_until`, `scene`; `seats.name`, `facing`; `submissions.name`. The prompts `explore`, the tools' descriptions, `view_image`, `view_image_kept`, `scene_plant`, the `side_` and `facing_` lines, and the controls in `instructions`.
- Harness seats, BASE-066: a seat written `acp:<agent>/<model>` is Claude Code, Codex or another agent dispatch starts, on the person's own login, never an API key, `harness.py`. A seat only reads: Claude Code's session is made with only its reading built-in tools and Metaform's MCP server, so the folder's own allow rules cannot let it write. `open` checks the agent against `dispatch agents` and resolves the model to a value the agent offers, `dispatch options`, by value, name or a full id ending with the name. Each seat is one dispatch session for the life of the table, started by `dispatch seat` on one held ticket per table, `Roundtable <N>`, closed when the table ends: its turns are the seat view through `message`, its reply the last text of the turn, the 512-character retry as for a model, a turn past `roundtable_agent_wait` interrupted and passed with no submission, a session that ends taking the seat away (`gone`, its turns skipped). The runner starts every harness seat as it starts and stops them with `dispatch stop session=` when the table ends. The tables go to version 2, compatible from 1: `discussions.seat_work`, and `seats.agent`, `model`, `cursor` and `gone`. The prompts `no_reply_harness` and `seat_gone`.
- The roundtable module, version one, BASE-066: a discussion among models at an Address, where a submission enters only when Jev finds it new, valuable, relevant and worth keeping, each at `roundtable_keep` or above. The verbs `open`, `comment`, `hold`, `continue`, `end`, `watch`, `status`, `list`, `read`, `turn`, `submit`, `submission`, `review` and `run`; the settings `roundtable_keep`, `roundtable_pause`, `roundtable_agent_wait` and `roundtable_reporter`; the tables `discussions`, `seats`, `submissions` and `waiting`, version 1; the resource templates `metaform://roundtable/discussion{discussion}/submission{submission}` and `metaform://roundtable/discussion{discussion}/review`. Seats are models through OpenRouter and agents that submit their own turns; ACP harness seats and A2A peer seats, MCP-040, are not built yet. Whoever opens a table names its seats; there is no default line-up. Ships enabled.
