# Reuse existing fulfillment

Locate the functionality through the map, receiving purposes, relationships and meaningful artifact references. Examine the existing realization and relevant work history before introducing another mechanism.

Compare the simplest adequate alternatives against the requested outcome, integration cost, failure behavior and maintainability. Reuse a working mechanism when it serves the purpose. Explain a material gap when a new mechanism is warranted. Keep related local reasoning in the current contribution when it needs no independent specialty or deliverable.
