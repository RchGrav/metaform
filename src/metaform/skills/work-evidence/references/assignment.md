# Faithful assignments

Preserve the user's source request and revisions as addressable source material. Distinguish source instructions, project evidence, interpretation and the proposed approach. Keep exact names, values, operations, exceptions and distinctions where they affect the contribution.

Give the receiving purpose, expected result, relevant functional locations, current decisions, available evidence and recorded return destination. Reference the rest of the source instead of copying an entire conversation. A summary helps navigation but does not replace the operative source.

For example, if a request says “leave justified holds in place”, retain that constraint in the handoff. “Review held work” alone does not preserve its exception.
