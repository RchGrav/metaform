# Outcome and evidence

Match each requested behavior to the observation that can establish it. Match that observation to the actual candidate, configuration and relevant environment. Exercise failure cases and the real user journey when needed to resolve a material uncertainty.

Compare failing test identities as well as totals when using a baseline. Two runs can each have one failure while failing different requirements. Distinguish established behavior, partial evidence, unknowns and claims the check does not cover.

Use the acceptance-scoped verification already appropriate to the assignment. Retain artifact references, observed results and limits in the existing result record. Repeating a passing check adds no evidence unless something changed or a concern remains.
