# Prompts

This folder contains prompts for maintaining and enhancing the Metaform project and other projects.

The prompts in [`metaform/`](metaform/) can be used in their current form to create specifications and plans for enhancing Metaform.

Use all prompts in this collection to guide improvements to Metaform’s capabilities for:

- Converting prompts.
- Enhancing the workflow engine to accommodate a variety of prompts and workflows.
- Generating the schemas needed to encode those workflows.

The ultimate goal is to tune and ingest the prompts in this folder into the Metaform platform as bundled workflows.
