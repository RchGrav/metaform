Facts that decide the design

  • Three tiers in Claude Code: always holds server instructions and tool names; on call holds tool definitions, tool results and resources the model reads; user holds prompts, @-mentions and elicitation.
  • A blind agent, one started by another agent, reaches only instructions, tool definitions, tool results and resources. It cannot run a prompt.
  • Tool search is on by default: only tool names and server instructions load at session start. ENABLE_TOOL_SEARCH=false loads every definition up front.
  • Each tool description and each server's instructions are cut at 2,048 characters. Put what matters first.
  • Annotations describe a whole tool. A tool that mixes read-only, additive and destructive commands cannot set one true hint.
  • Stdio servers connect on the older protocol, with initialize, unless MCP_PROTOCOL_NEGOTIATION=auto is set.
  • Deprecated in 2026-07-28: Roots, Sampling, Logging. Migrations: tool parameters or resource URIs; direct provider APIs; stderr or OpenTelemetry.
  • The spec has no length limits of its own on these strings. Every character limit on this sheet is Claude Code's or the SDK's.
