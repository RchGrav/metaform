Gate recommendations

This report covers all 43 entries from the earlier checklist. Each checkbox records your review. Each recommendation states what Metaform should change and why. The tables name the individual controls within each combined entry. The pros and cons describe removing the stated restriction. Removing a worker ban does not remove the control itself. Metaform must keep the specific replacement checks described below. I changed no application code for this report.

Worker means a project agent. The user agent carries your instructions. Agent tools means the Metaform tools connected to an agent. The terminal accepts Metaform text commands. Workers can use the terminal without starting another worker. A map note records information about one part of the project.

Workers have equal authority. Metaform launches workers when slots become available. Requesting another worker gives the requester no control over that worker. Metaform manages normal worker shutdown. You and the user agent can direct worker shutdown. Workers must not shut down your computer or Metaform. Workers must not use your credit cards.

[ ] 1. Metaform can block workers from changing settings

  • Now: Metaform can block changes to worker limits, model choices and automatic starts. An existing setting can disable this restriction.
  • Recommendation: Metaform should replace worker-based bans with the exact control rules below.
  • Why: A worker's label cannot establish whether a setting change respects capacity, spending or account boundaries.
  • After removal: Workers could change these settings when they meet the conditions listed below.
  • Pros: Workers could adjust settings needed for their assigned work.
  • Cons: Workers could expand capacity, spending or account access if Metaform also removed the listed replacement checks.
  • Source: Settings check.
