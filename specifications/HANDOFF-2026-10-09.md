## How to work

- **Test budget, CLAUDE.md.** While working, run only the test files for the code changed, in one `pytest` call. Before each commit, run the default `pytest` once: it leaves out browser tests, takes about 70 seconds and passes with no failures. Browser tests run with `pytest -m browser -k <name>`, only when `app.js`, `index.html`, `app.css` or the web server changed. Never compare against main file by file, and never rerun a suite that passed. Every subagent brief carries these rules.
- **The owner is never named or quoted** in code, comments, tests, specs, docs or commit messages. `tests/test_shipped_text.py` fails on any line in `src/metaform` or `tests` that names him. Specs say "confirmed, <date>" and state decisions in plain words.
- **After editing `app.js`,** check it parses as a module: `node --input-type=module --check < src/metaform/modules/web/page/app.js`. A plain `node --check` misses duplicate declarations, which broke the page twice.
- **Restart the page after merging page or server code:** `metaform web stop` then `metaform web start`, from the checkout's `.venv`.
- **Work in worktrees, merge one at a time,** and resolve conflicts keeping both sides' intent; the name removal and feature work touched the same files twice overnight.
