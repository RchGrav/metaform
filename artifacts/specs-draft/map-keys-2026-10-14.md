## Proposed amendment, 2026-10-14

Each digit cycles one setting, never several digits for one setting, and each press briefly says the new value
at the 2D map's corner. **1** cycles the large 3D map's zoom on the selection: the selected name at a quarter,
a half or three quarters of the view's width. The small area takes no zoom, and always meets a node selected
on either map at four fifths of its width, whether node zoom is on or off. **2** cycles the flow: off, hover,
the selection, all and live with the joins' lines drawn, then those five again with the lines hidden
(web_flow_mode, web_flow_edges). **3** switches the 3D layout between Organic and Flat (web_physics). **4**
belongs to the map depth, ticket code.interface.graphical#24. **0** and Home put both maps in full fit. The 3D
Whole and Free modes stay for agents and have no key or control for the person.

**A** cycles which agent the person follows: none, then each agent on the map in turn, oldest first, then none
again. If the followed agent leaves the map, the person follows the newest agent still on it, or none. **V**
switches between the person's view and the followed agent's view. In the agent's view the large 3D map shows
what the agent's own eye camera sees, the same camera web_see and web_look use. It moves with the agent, never
orbits, and no flight or hand moves it. If the 3D map is moved into the small area, the person's view comes
back. The View menu has no key.

The 2D map is fit-all. A selection, an agent's start or a redraw leaves it fitted, or where the person's wheel
or drag left it. While the person follows an agent, the 2D map frames that agent's node and the parts one join
away, and follows the agent from node to node. When the person stops following, the map goes back to full fit.

Why: several digits each set part of one setting, and a letter repeated a digit, so no key could be learned as
"this key, this setting". The person watching agents work needs to follow one agent and see what it sees, and
the 2D map is read best whole except when it follows an agent.
