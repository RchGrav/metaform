MCP protocol
- Uses the Tasks extension's stable 2026-07-28 specification, not the earlier experimental per-tool task model.
- Durable assignment precedes launch and CreateTaskResult. Clients declare io.modelcontextprotocol/tasks, otherwise async launch returns the specified -32021 capability error before execution.
- Flat task handles, tasks/get, tasks/update and tasks/cancel use the official result envelopes. Native input requests persist distinct keys; duplicate/unknown responses are ignored. Accepted input is durably queued for delivery.
- Cancellation is cooperative. Terminal records are immutable. Native/tool execution errors complete with isError, distinct from failed JSON-RPC operations.
- Native session events update status. Client polling does not introduce a background server polling loop.
- Source references: https://modelcontextprotocol.io/llms.txt and https://github.com/modelcontextprotocol/ext-tasks/blob/main/specification/2026-07-28/tasks.md
