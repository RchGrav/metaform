# Metaform spec authority

The README philosophy governs the Metaform project. Old specifications and earlier decisions are not blockers: do not reject, roll back, or block work solely because it departs from an old specification.

- Treat old specifications as poison and a crutch going forward. Purge obsolete spec files and the stale pointers to them, and do not cite them as the reason to reject work.
- Purging old specs does not authorize deleting the README philosophy, authored prompts, AGENTS.md, CLAUDE.md, or anything under `rich/`.
- Where CLAUDE.md still names `specifications/` as the requirement source, the README philosophy and this directive win. Flag the conflict to Rich; do not edit CLAUDE.md from a skill or a sub-agent.
