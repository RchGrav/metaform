flow2d.js: per edge, created once in g.flows2d right after .edgePaths, each train is one g holding one path whose round-capped zero-length dashes are its full-strength dots plus one single-dot path per fading dot (0.75/0.5/0.25), moved by one CSS custom property, --head, on the train's g, the only per-frame write for a train; the request is one single-dot path (strokeDashoffset); record rect and ring circle stay one element each. Display is written only when a shape's state changes (show2d), the group opacity only when it changes, colours once at creation. Choice: the dot paths run through the edge's sampled polyline with pathLength = getTotalLength, because Chromium measures a Bezier's dashes 0.6-2.4 px shorter than getTotalLength on Mermaid's curved edges (measured on all 70 edges), which dropped the dot at an edge's end.
