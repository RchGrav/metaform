Vendor addresses are versioned at serve time: vendor_version() digests every vendor file's path, size and mtime (worked out again on each index.html load), and sent_bytes() rewrites every quote- or paren-preceded /vendor/ in page .html/.js/.mjs/.css to /vendor/v-<16 hex>/. /vendor/v-<current>/… is answered public, max-age=31536000, immutable; unversioned and stale-version addresses stay no-cache plus ETag. ... Do not import a vendor file by a path the import map also covers, or the browser loads two instances (the 'Multiple instances of Three.js' test catches it).
