**The fix:** placement runs and launch receipts now go to `~/.metaform/projects/<id>/source_placement/`, made 0700, instead of the project folder. Both the launch path in `__init__.py` and the run path in `pipeline.py` use a new helper, `runs_root(project_id)`. A new start-hook step, `_move_runs`, moves old run folders out of `<project>/.metaform/refactor` and `.metaform/source_placement` into the home, and removes `.metaform` only if it's then empty.
