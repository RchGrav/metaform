Test gotcha: run(...) reloads a2a_out, so a send from inside a CLI call goes through a module copy whose TRANSPORT is unpatched, and it is invisible to a Recording transport. To prove a CLI call makes no peer call, monkeypatch httpx.AsyncHTTPTransport.handle_async_request (a reload does not replace it). Scratch tests outside the repo load the repo conftest with: uv run python -m pytest -p conftest <file>.
