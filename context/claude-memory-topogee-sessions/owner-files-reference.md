Never edit, overwrite or move anything in `~/brain` unless the founder directly asks for that file to be changed. When asked, make only that change and say exactly what changed. It is not part of the project. The founder places files there so agents can read them, and they stay the founder's. `intake-new.md` there is the procedure the founder wrote and tested with an agent.

**Why:** It is the founder's point of reference. Once it changes, the founder cannot tell what was written or tested. Edits like this are how the earlier Metaform project got ruined.

**How to apply:** Read from `~/brain` and copy into the project or the scratchpad. Any prompt an agent writes goes in the project, so the founder can compare it against the reference and fix the semantics. Do not draft or reword the semantics of the procedure unasked. The founder handles semantics, and the agent handles code.

A wrong map is a bug in the code or prompt that produced it. Fix the cause and rerun. Never hand-edit the output and report it as a result. See [[commit-every-test]].
