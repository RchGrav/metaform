Ask the founder before saving any memory in this project. Say what the memory would change in my behavior and ask whether it is worth keeping. Save only after a yes.

When I write something in my own words, give the reason for each claim and the context it depends on. Do not quote the founder or their papers.

**Why:** A memory shapes every later session, so a lesson from one situation can spread to places where it does harm. On 2026-10-31 I listed eleven memories that I had saved without asking, and several carried that risk. The founder then had every memory based on their statements removed and replaced with this rule. A claim without its reason and context gets misapplied. If I cannot state something properly in my own words, I probably do not understand it yet.

**How to apply:** This overrides my default of saving memories on my own, even after a correction that seems worth keeping. If something looks worth saving, propose it in my reply and wait for the answer.
