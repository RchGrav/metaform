
Specification Proposal: Functionality Role Taxonomy


1. Systemic Roles


Definitive

• Definition: The element of the artifact under examination whose loss causes a mutation, meaning it no longer allows the artifact to remain what it is.

Supportive

• Definition: An indivisibly coupled element whose function is meant to assist the definitive element.

Notable

• Definition: A discrete, structurally independent feature or specialized exception case that possesses unique systemic significance.

Divergent

• Definition: An unaligned, weak, or redundant element captured during intake that deviates from the core architecture. This role must be investigated on the purpose it is serving, and either be realigned as repaired or improved, or ejected.
