# Audit: implementation against the owner's design

Read-only audit, 2026-11-05. Working tree as found. No code was changed, no model was called, no table was started.

## 1. Summary

The code follows the owner's material in most mechanics, but 16 items differ, 10 are missing, and 38 builder additions have no owner basis. The JEV contribution checks now match `archaeology/roundtable-jev-checks.md` word for word: a script checked all nine strings, so the example failure is fixed in this tree. The rating prompt still differs. It uses the builder's wording and category keys, and it drops the anonymity notice. The most serious differences concern text agents receive:

- The rating request.
- The credit promise in the owner's template, which the code does not always honor.
- The mechanics block appended to the owner's prompt.
- The topic poll, which excludes busy agents.

Score results, the scorecard receipt, the profile in later sessions, and accolades are not built at all. Ratings never accumulate across tables, because every table opens new sessions and therefore gives each agent a new genesis name. There are 15 open questions where owner documents conflict, and 6 owner quotes in code comments that appear in no owner document.

**Sources.** R = `README.md` (identical to `roundtable_functional.md`, checked with `cmp`). D = `Roundtable_ACP_Integration_Design.md`. T = `docs/TRACEABILITY.md`; only quoted owner words count as authority. TPL = `crates/roundtable/resources/participant_prompt.md`. **(P)** = archaeology file, provisionally authority pending owner confirmation. `ratings.md` = `archaeology/docs/reference/roundtable-agent-ratings.md`. `catalogue` = `archaeology/review/all-prompts.md`. Code paths are relative to `crates/` unless stated.

**Safety-relevant items** (listed in detail in section 4):

- B28: the permission policy allows any request that names no path, including shell commands.
- B26 and B29: the OpenCode permission config and the automatic key sharing.
- B30: chair token and host checks.
- D14: shutdown timers against "no timers".
- D15: AgentSight observes nothing without root.
