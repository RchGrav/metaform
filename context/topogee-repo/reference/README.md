# Preserved reference material

Evidence, not a competing current specification. Start from ../SPECIFICATION.md and ../DECISIONS.md.

- theory/: primary preprint and technical reference. Read them to understand functional intent, RE/PE perspective and relational identity.
- intake/: authored/historical intake variants, axioms and latest owner-original schema. Protected, byte-preserved. Historical copies contain known later edits/obsolete serialization; none is installed as a pristine active prompt by this bootstrap.
- ecs/: complete supplied ECS/terminology paper packet with its source contracts. Grounding for context delivery, not an approved Ladybug physical schema.
- architecture/: chassis/module/CLI/quality contracts and multi-user Node deployment design. Node is the module/deployment name, not necessarily Node.js. Old backend details do not override Ladybug.
- python-module-template/: permitted reference template, not an installed application/runtime choice.
- corrected-handoff/: corrected source package and provenance, including original preserved sources. Its candidate/version/authority labels remain intact.
- original-handoff/: original handoff context where recovered.
- repository-review/: landed implementation/reuse/backend/CLI review. Clean rebuild decision supersedes plans to bulk-adapt existing code; review capabilities still inform parity.
- recovered-orchestration/: old branch scoring/orchestration evidence. Current averaging and lifecycle decisions supersede old cumulative/context/reset behavior.
- proposals/: Gemini interface/backend/build documents retained for critique. They contain schema/semantic mistakes; do not execute them as build instructions.
- history/: chronological decision log, including corrected/abandoned proposals. Later decisions govern earlier entries; the current spec is the readable synthesis.

Original bytes are checked against ../source-register.json. Relative links within historical documents may refer to the original repository; use the current spec/reference directory map to locate the relevant source. Do not globally rewrite evidence to repair those historical links.
