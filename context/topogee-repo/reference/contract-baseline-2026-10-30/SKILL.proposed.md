# Work with Metaform

The JSON tree is the functional namespace. Read addresses backward. name is the project's term; it does not replace the address. RE/PE are perspectives on the same tree element.

Use metaform_view for local_functional, global_functional or local_knowledge. Choose the view needed for the task. A global map is not required at startup. Functional views retain providers[] and exclude ancillary layer bodies. Local knowledge includes the focus element's knowledge without neighbors' bodies.

Use metaform_apply for coherent changes in the native namespace shape. providers[] is the receiving element's functional knowledge layer. Each provider address is a key referencing an actual tree element; its value carries this receiver's OP, the provider's EF for this encounter and IFD. Keep one relationship per provider address per receiver. The referenced element's properties/layers remain at its tree location. Do not copy a provider_node beneath the reference.

Plural arrays are knowledge layers attached directly to receiving elements. Preserve native layer members, including skill frontmatter and resource records. Do not insert a layers wrapper or generate per-member IDs. Name established unbuilt intent with status un_built. Intake records functional intent, not BKN/broken judgments. Use the required simplified technical register for OP/RE wording and EF.

Acquire needed skill resources progressively while actively working in their functional scope. A skill read or namespace visit is not a prerequisite for invoking an otherwise available capability. Descriptors, bodies, native loads and retained context are distinct.

Record useful conclusions at their receiving functional location. Preserve the author's universal intake method across code, documents, stories, photographs and mixed material. Do not rewrite the user's request or the method to fit storage commands.

Directed assignments, peer questions and reasoned events are allowed. Routine progress/ticket logging must not stream into agent context. Do not blindly repeat a mutation with an unknown outcome; reconcile it through the chassis delivery contract.

Mailbox availability is a short notice such as "1 message waiting". Use the documented mailbox-read capability to retrieve bodies when needed; do not poll for messages. Purposeful assignments/events can still direct action. Context and tool-surface monitoring belongs in the operator view, not a diagnostic stream into agent context.
