# Inference Metaform — Review Delivery

**Start with `START-HERE.md`.** It explains what this delivery contains and where to look first, without assuming that the working specification is already adopted.

The complete three-part work is in `Inference-Metaform-Revised-Paper-and-Specification.md`, built from the three numbered documents. These are review drafts, not an approved or implemented system.

`contracts/` contains proposed graph, Cypher and JSON schemas, examples, and MCP wire fixtures. `sources.md` inventories references. `verification/` contains the available local fixture checks and notes the integration work that was *not* run.

Terminology revision: **ECS** means **Entity-Component-System** in Bevy or other ECS frameworks; **Resource** is a shared-data facility within such a runtime. The **Inference Metaform functional graph** in LadybugDB is *not* an ECS runtime, and this work no longer proposes ECR as an architecture name. The three paradigms share contextual presentation and MCP contracts, not a mandatory common execution architecture.

The revised archive preserves the original supplied design contracts and verification records. No system behavior, repository implementation or benchmarks are represented as proven by this terminology correction.
